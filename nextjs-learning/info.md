## 책 소개

Next.js full stack service building guide.

## 이 책을 선택한 이유

- Next.js를 배우고, React 학습에 이어서 나아가기 위해.
- 해외 유명 저자가 써서.
- 이 책을 읽기 전에 부족하다고 느낀 부분은 무엇인가? React는 프론트엔드 라이브러리라, 풀스택과 프레임워크가 필요했다. 

## 학습 목표

책을 다 읽었을 때 할 수 있어야 하는 행동을 작성합니다.

- [ ] Next.js의 렌더링 방식을 설명할 수 있다.
- [ ] App Router 기반 애플리케이션을 구성할 수 있다.
- [ ] 캐싱과 데이터 갱신 전략을 상황에 맞게 선택할 수 있다.

읽기 전 기준으로 이미 알고 있는 내용을 기록합니다.
