## CHAPTER 1 처음 만나는 타입스크립트

* 타입스크립트(TypeScript): 자바스크립트의 슈퍼셋 언어. 기존 자바스크립트의 모든 문법과 기능을 사용할 수 있으면서도 기능이 확장된 언어.
* 시맨틱 버저닝(semantic versioning)
    - 메이저 버전.마이너 버전.패치 버전
    - 메이저 버전: 기존 버전과 호환이 되지 않으며, 큰 변경사항이 있을 때 올림
    - 마이너 버전: 기존 버전과 호환이 되면서, 기능이 변경되거나 추가되었을 때 올림
    - 패치 버전: 기존 버전과 호환이 되면서, 가벼운 버그를 고쳤을 때 올림.

- 타입스크립트의 장점
    1. 개발 생산성
    2. 안정성
    3. 확장성
    4. 호환성
    5. 거대한 커뮤니티

* 타입스크립트의 활용
    - 일렉트론
    - 리액트 네이티브
    - NestJS
    - Express.js
    - React
    - Vue.js
