#### 3.1.1 주석

- 주석(comment): 개발하는 사람 눈에만 보이고 실행하는 컴퓨터에게는 없는 글자로 인식됨.
- 컴파일러(compiler): 소스 코드 전체를 한 번에 저수준 언어 또는 기계어로 번역하여 실행하는 방식. C, Java
- 인터프리터(interpreter): 한 문장씩 번역하여 실행하는 방식. JavaScript, Python.


#### 3.1.2 변수의 선언

* 변수란 데이터를 저장하는 공간을 말함.
* 메모리에 데이터 저장 공간을 만드는 것: 변수를 선언한다.
* 선언된 변수에 데이터를 집어넣는 것: 변수에 값을 할당한다.

* 타입스크립트에서 변수명을 지을 때의 범용적인 규칙
    1. 변수명의 첫 글자는 영문자, 달러($), 언더바(_)만 올 수 있다.
    2. 두 번째 글자부터는 영문자, 달러($), 언더바(_), 숫자만 올 수 있다.
    3. 변수명의 영문자는 대문자, 소문자를 구분한다.
    4. 예약어가 아니어야 한다.
    5. 보통 변수명은 캐멀 케이스로 짓는다(필수 아님.)

* 파스칼 케이스(Pascal case): 단어마다 첫 글자가 대문자이며, 시작하는 글자는 대문자
* 캐멀 케이스(camel case): 단어마다 첫 글자가 대문자이며, 시작하는 글자는 소문자(낙타를 닮음)
* 스네이크 케이스(snake case): 단어 사이에 언더바(_)가 있고, 모든 단어는 소문자(뱀을 닮음)


#### 3.1.3 원시 타입 변수

* **콜 스택**(call stack): 함수의 호출과 관련된 정보를 저장하는 영역이며, 처리 속도가 빠르고 구조가 단순함.
- **콜 스택에 직접 저장**되는 변수들을 **원시타입 변수**(primitive type variable)라고 하며, 타입스크립트의 원시 타입 변수는 6개.

* **힙**(heap): 주로 동적으로 할당되는 데이터(예: 객체, 대규모 배열 등)를 저장하는 영역이며, 자유롭게 확장할 수 있는 구조라서 관리가 복잡하고 메모리 누수의 위험이 있음.

* 타입 스크립트의 원시 타입 변수 6개.
    1. 숫자(number)
    2. 불리언(Boolean)
    3. null: **의도적**으로 아무것도 할당하지 않음을 표시할 때 사용.
    4. undefined: null과 마찬가지로 아무 값도 없음을 듯함.
    5. 문자열(string)
        - 백틱[`]: 백틱으로 감싼 것들은 모두 문자열이 되며 ${code}를 중간에 넣어서 문자열로 만들 수 있음. 괄호 사이에는 변수, 계산식, 함수 등 다양한 것이 들어갈 수 있음.
    6. 심벌(symbol): 하나뿐인 고유한 값을 만들 때 사용함.
