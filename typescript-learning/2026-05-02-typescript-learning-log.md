### 1.1 웹 개발의 역사

    - 웹 사이트 vs 웹 애플리케이션
        * 웹 사이트: 단방향 정보 제공. 사용자와 상호 작용하지 않음.

    - 컴포넌트 베이스 개발(CBD, Component Based Development) 방법론 등장.

## 2장 타입

### 2.1 타입이란
    - 2026-05-03 일요일
    - 21:31 ~ 21:59 (28m)
    - 33~41쪽.

    * 정적 타입 vs 동적 타입
        * 정적 타입 시스템: 모든 변수의 타입이 컴파일타임에 결정됨. C, Java, TypeScript.
        * 동적 타입 시스템: 변수 타입이 런타임에서 결정됨. Python, JavaScript.

    * 컴파일타임과 런타임
        * 컴파일 타임: 기계가 소스코드를 이해할 수 있도록 기계어로 변환되는 시점
        * 런타임: 이후 변환된 파일이 메모리에 적재되어 실행되는 시점

    * 암묵적 타입 변환(Implicit coercion/conversion)
    * 암묵적 타입 변환 여부에 따라, 타입 시스템을 강타입(strongly type)과 약타입(weakly type)으로 분류할 수 있다.

    * 타입 시스템
        - 명시적으로 알려줘야 하는 타입 시스템
        - 자동으로 타입을 추론하는 타입 시스템

    * **타입스크립트가 탄생한 이유는 사람이 이해하기 쉬운 방식으로 코드를 작성하기 위해서가 아니라, 자바스크립트의 컴파일타임에 런타임 에러를 사전에 잡아내기 위한 것이다.**
        - 타입스크립트를 컴파일 -> 타입이 모두 제거된 자바스크립트 소스코드
