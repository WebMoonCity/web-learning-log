### 1.1 웹 개발의 역사
    - 크로스 브라우징(Cross Browsing) 이슈
    - 웹 사이트 vs 웹 애플리케이션
        * 웹 사이트: 단방향 정보 제공. 사용자와 상호 작용하지 않음.
        * 웹 애플리케이션: 쌍방향 소통의 웹. 사용자와 상호작용. Ex) Google Maps
    - 컴포넌트 베이스 개발(CBD, Component Based Development) 방법론 등장.
    - 개발자 협업의 필요성 증가
