### 5.8 interface vs. type

- 인터페이스에는 interface 키워드로 만드는 인터페이스가 있고, type 키워드로 만드는 인터페이스가 있으며, 이 둘에는 차이가 있음.

- 타입의 확장에서 차이가 있음.
    - interface로 만든 인터페이스는 extends를 사용해서 타입을 확장함.
    - type으로 만든 인터페이스는 인터섹션 타입을 사용함.

* **type 키워드로 만든 인터페이스는 유니온 타입과 인터섹션 타입의 사용이 자유롭다** 보니, 더 유연한 타입을 가질 수 있음. 그뿐만 아니라 유틸리티 타입과 함께 사용할 때도 저장을 할 수 있기 때문에 클래스와 함께 사용할 경우를 제외하고는 보통 type 키워드를 사용함.

- 유틸리티 타입: 기존 타입을 재료로 삼아 새 타입을 만드는 TypeScript 내장 도구.
    - 예: `Omit<User, "id">;` `Partial<>;` `Pick<User, "id" | "name">;`
