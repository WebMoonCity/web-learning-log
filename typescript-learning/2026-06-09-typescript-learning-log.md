#### 6.3.2 데이터베이스 설치 및 연결

214쪽 ~

- 몽고DB는 '_id'라는 기본 키(primary key)가 있음. 이 타입은 Object Id라는 특수한 타입을 사용함. 이는 prisma 라이브러리에서 제공하는 기능을 활용해 작성한 것. 실제 데이터베이스에는 _id로 저장되며, _id를 id에 매핑시켜 NestJS에서는 id로 사용할 것.

- 215쪽 1번 primsa 오타 있음. primsa -> prisma

- ORM을 이용해서 데이터베이스의 정보를 가져올 수도 있고, 주입할 수도 있음. 이번에는 스키마(schema)를 바꿔서 정보를 주입(push)함.

- ORM은 schema.prisma로 데이터베이스의 정보를 알 수 있음. 몽고DB는 push 명령어로 정보를 알 수 있었음.
