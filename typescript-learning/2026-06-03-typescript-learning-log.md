#### 6.2.2 메인 페이지

- 큰아버지 흉물과 친가와 어머니와 동생에 대한 분노가 올라왔다. 그러나 마음을 정렬하고 공부하려고 한다. 내가 정신적으로 경제적으로 학업적으로 강해질수록, 풀리지 않았던 문제는 해결하기 쉬워진다.
* 분노를 공부의 이유로 바꾸자.

- `??`: null 병합 연산자
    - 앞에 것이 null 또는 undefined이면 뒤에 것(기본값)으로 넘어간다.
    - (ex) `props.title ?? "Living room Sofa"`: props.title이 null 또는 undefined이면 "Living room Sofa"를 사용한다.

#### 6.2.4 글 작성 페이지

- useCallback: React에서 제공하는 Hook, 컴포넌트가 다시 렌더링되어도 같은 함수를 재사용하게 해주는 것.
    - 형태:
        ```JavaScript
        const 함수 이름 = useCallback(() => {
            // 실행할 코드
        }, [의존성]);
        ```
- 리액트에서 훅(Hook)이란? 함수 컴포넌트 안에서 React의 기능을 사용할 수 있게 해주는 함수.
- useMemo = 기억하는 것: 값
- useCallback = 기억하는 것: 함수
- @types가 붙은 패키지: 기존 자바스크립트 패키지 위에 타입을 입혀주는 패키지.
