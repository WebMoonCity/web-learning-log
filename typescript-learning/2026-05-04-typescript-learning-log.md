## 2장 타입

### 2.2 타입스크립트의 타입 시스템
    - 2026-05-04 월요일
    - 01:29 ~ 02:35 (66m)
    - 46 ~ 66쪽.

    * 타입스크립트가 구조적 타이핑을 채택한 이유: 타입스크립트가 자바스크립트를 모델링한 언어이기 때문.
    * 덕 타이핑(duck typing): 어떤 함수의 매개변숫값이 올바르게 주어진다면 그 값이 어떻게 만들어졌는지 신경 쓰지 않고 사용한다. 어떤 타입에 부합하는 변수와 메서드를 가질 경우 해당 타입에 속하는 것으로 간주하는 방식.

    * 값 vs 타입
        - 값(value): 프로그램이 처리하기 위해 메모리에 저장하는 모든 데이터. 값은 할당 연산자인 =으로 작성함.
        - 타입: 주로 타입 선언(:) 또는 단언 문(as)으로 작성함
        - 값과 타입은 타입스크립트에서 별도의 네임스페이스에 존재함.

    * 구조 분해 할당(Destructuring assignment): ES6부터 도입된 자바스크립트의 기능으로 자바스크립트 또는 타입스크립트에서 배열이나 객체의 속성을 개별 변수로 분해하여 그 값을 변수에 할당하는 것을 말한다.

    * 유니온 타입: 어떤 값이 여러 타입 또는 여러 값 중 하나일 수 있음을 표현하는 TypeScript의 타입 문법.
    * 트리쉐이킹(tree-shiaking): 자바스크립트, 타입스크립트에서 사용하지 않는 코드를 삭제하는 방식.

    * typeof: 연산하기 전에 피연산자의 데이터 타입을 나타내는 문자열을 반환.
        - typeof 연산자가 반환하는 값: 자바스크립트의 7가지 기본 데이터 타입(Boolean, null, undefined, Number, BigInt, String, Symbol)과 Function(함수), 호스트 객체 그리고 object 객체.
        - 값에서 사용된 typeof는 자바스크립트 런타임의 typeof 연산자가 됨
        - 반면 타입에서 사용된 typeof는 값을 읽고 타입스크립트 타입을 반환함.

    * 타입스크립트에서는 타입 단언이라 부르는 문법을 사용해서 타입을 강제할 수도 있는데 as 키워드를 사용하면 된다.
    * 타입 가드(Type Guard): 특정 조건을 검사해서 타입을 정제하고 타입 안정성을 높이는 패턴.

### 2.3 원시 타입
    - 2026-05-04 월요일
    - 04:13 ~ 04:33 (20m)
    - 66 ~ 71쪽.

    1. boolean: 오직 true와 false 값만 할당할 수 있다.
    2. undefined: 정의되지 않았다는 의미의 타입으로 오직 undefined 값만 할당할 수 있다. 초기화되어 있지 않거나 존재하지 않음을 나타냄.
    3. null: 오직 null만 할당할 수 있다. 자바스크립트에서 보통 빈 값을 할당해야 할 대 null을 사용함. 사용된 null은 명시적, 의도적으로 값이 아직 비어있을 수 있음을 보여줌.
    4. number: 자바스크립트의 숫자에 해당하는 모든 원시 값을 할당할 수 있음. 자바스크립트의 숫자는 정수, 부동소수점수를 구분하지 않기 때문에 모두 number 타입에 할당할 수 있음. NaN이나 Infinity도 포함.
        * NaN: Not A Number의 줄임말로 숫자가 아님을 나타냄.
        * Infinity: 무한대를 나타내는 숫자형 값.
    5. bigint: 이전의 자바스크립트에서는 가장 큰 수인 Number.MAX_SAFE_INTEGER(2^53-1)를 넘어가는 값을 처리할 수 없었는데 bigInt를 사용하면 이보다 큰 수를 처리할 수 있음. number 타입과 bigint 타입은 엄연히 서로 다른 타입이기 때문에 상호 작용은 불가능.
    6. string: 문자열을 할당할 수 있는 타입. 공백도 string 타입에 해당함. 작은따옴표(')나 큰따옴표(")로 둘러싼 문자열말고도 백틱(`)으로 감싼 문자열 내부에 변숫값을 포함할 수 있는 템플릿 리터럴(template literal) 문법도 있음.
    7. symbol: Symbol() 함수를 사용하면 어떤 값과도 중복되지 않는 유일한 값을 생성할 수 있음. 타입스크립트에는 symbol 타입과 const 선언에서만 사용할 수 있는 unique symbol 타입이라는 symbol의 하위 타입도 있다.
