#### 6.3.3 API 구축

* NestJS 핵심 구성 요소 3가지.
    * 모듈: NestJS 애플리케이션을 구성하는 핵심 요소 중 하나로 기능 단위.
    * 서비스: 보통 비즈니스 로직, 데이터처리 레이어로 쓰임. 앞서 준비한 몽고DB와 상호작용을 할 레이어.
        * 의존성 주입: 객체지향 프로그래밍에서 객체 간의 의존 관계를 관리하는 디자인 패턴으로, 간단히 말해 직접 의존성을 생성하거나 관리하지 않고 외부에서 제공받는 방식. @Injectable 데커레이터가 있따면 클래스를 의존성으로 관리한다는 뜻.
    * 컨트롤러: 요청(request)을 처리하고 응답(response)을 반환함. 클라이언트로부터 들어오는 요청을 처리하고, 응답을 반환하는 역할을 함.


- 중간 궁금한 것 정리
    * React = 화면 만드는 기본 도구
    * Next.js = React로 실전 웹사이트를 만드는 프레임워크
    * NestJS = 백엔드 서버/API를 만드는 프레임워크
    * Vercel = React/Next.js 사이트를 배포하는 플랫폼

- NestJS에서 요청은 **컨트롤러**가 받게 됨. 그다음으로 컨트롤러가 **서비스**에게 책임을 위임하여 로직을 처리하게 됨.
