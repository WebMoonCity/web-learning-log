# 핵심만 골라 배우는 SwiftUI 기반의 iOS 프로그래밍

> 이 파일의 서지 정보는 2023년 개정증보판 기준이다. 소장본이 2020년 초판이라면 판, ISBN, 출간일, 기술 기준을 책의 판권면에 맞게 수정한다.

## 이 책으로 얻을 것

- Swift의 핵심 문법을 읽고 작은 코드를 직접 작성한다.
- SwiftUI의 뷰 구성, 레이아웃, 상태와 데이터 흐름을 자기 말로 설명한다.
- 책을 보지 않고 여러 화면을 가진 작은 iOS 앱을 만든다.
- 책과 현재 Xcode의 차이를 공식 문서로 확인하고 스스로 수정한다.

## 학습 방법

주 5일, 하루 60~90분을 기본으로 한다.

1. 전날 회상: 10분
2. 새 내용 읽기: 20분
3. 예제 구현과 변형: 30~45분
4. 학습 로그 작성: 10분

각 예제는 다음 세 단계로 다룬다.

1. 책을 보며 그대로 실행한다.
2. 책을 덮고 최소 기능을 다시 만든다.
3. 값, 레이아웃, 상태 처리 중 하나 이상을 바꾼다.

4~6개 장마다 배운 기능을 묶은 미니 앱을 하나 만든다. 문법에서 반복해서 막히는 부분만 별도로 보충하며, 긴 필사나 책 내용의 전사는 피한다.

### 학습 일차 기록 규칙

- `누적 실학습일`: 실제로 공부하고 로그를 작성한 날만 센다.
- `시작 후 경과일`: 학습 시작일을 1일차로 하여, 공부하지 않은 날까지 포함해 달력 기준으로 센다.

예: 2026-08-14에 시작하고 2026-08-17에 두 번째로 공부했다면 `누적 실학습일 2일`, `시작 후 경과일 4일차`다.

## 한 장의 완료 기준

- [ ] 핵심 개념을 자기 말로 설명할 수 있다.
- [ ] 예제를 보지 않고 최소 형태로 다시 만들 수 있다.
- [ ] 기능을 하나 이상 변형하고 결과를 예상할 수 있다.
- [ ] 발생한 오류의 원인과 해결 방법을 설명할 수 있다.

## 버전 기준

| 항목 | 책의 기준 | 현재 학습 환경 |
| --- | --- | --- |
| Xcode | 14 | 26.5 (17F42) |
| Swift | 5.7 | 6.3.3 (Command Line Tools) |
| iOS | 16 | Xcode 프로젝트를 만든 뒤 배포 대상 기록 |

책의 코드가 현재 환경에서 다르게 동작하면 날짜별 로그의 `버전 차이`에 다음 세 가지를 남긴다.

- 책의 방식
- 현재 환경에서 동작하는 방식
- 차이가 생긴 이유와 확인한 공식 문서

## 복습 규칙
