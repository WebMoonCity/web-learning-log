#### 09.14 클로저 표현식

* **클로저(closer)**, **클로저 표현식(closure expression)**
    - 클로저 표현식: 독립적인 코드 블록. 이름을 갖지 않으며, 매개변수와 반환 타입은 괄호 안에 포함되고, 클로저 표현식 코드의 시작을 가리키기 위하여 in 키워드를 사용함. ***사실, 함수는 이름이 있는 클로저 표현식.***
    ```swift
    {(<매개변수 이름>: <매개변수 타입>, <매개변수 이름>: <매개변수 타입>, ... ) -> <반환 타입> in
        // 클로저 표현식 코드가 온다.
    }
    ```
    - 클로저 표현식은 비동기 메서드 호출에 대한 완료 핸들러를 선언할 때 종종 사용됨.
