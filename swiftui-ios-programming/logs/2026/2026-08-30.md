#### 05.06 타입 애너테이션과 타입 추론

- **타입 애너테이션(type annotation)**

- 타입 애너테이션 없이 상수를 선언하게 될 경우에는 반드시 선언 시점에 값을 할당해야 함.
- 상수를 선언할 때 타입 애너테이션을 사용하면 나중에 값을 할당할 수 있음.
- 상수에 값을 할당하는 것은 오직 한 번 뿐.

#### 05.07 스위프트 튜플

* **튜플(tuple)**, 스위프트 프로그래밍 언어에서 가장 단순하면서도 강력한 기능을 가진 것들 중 하나.
    : 여러 값을 하나의 항목으로 임시적으로 그루핑하는 매우 간단한 방법.

- 튜플이 가진 강력한 기능은 하나의 함수에서 여러 값을 반환할 수 있다는 점.

#### 05.08 스위프트 옵셔널 타입

스위프트 옵셔널 데이터 타입은 대부분의 다른 프로그래밍 언어에 없는 새로운 개념.
옵셔널 타입의 목적은 변수 또는 상수에 값이 할당되지 않은 상황을 처리하기 위해 안전하고 일관된 접근 방식을 제공하는 것.

변수를 선언할 때, 데이터 타입 애너테이션 다음에 '?' 문자를 두어 옵셔널이 되게 함.

다음은 index라는 이름의 Int 타입의 변수를 옵셔널로 선언하는 코드.
`var index: Int?`

- 래핑되었다(wrapped)
- 강제 언래핑(forced unwrapping)

- 옵셔널 바인딩(optional binding)

- 암묵적으로 언래핑(implicitly unwrapped)

#### 05.09 타입 캐스팅과 타입 검사

* **타입 캐스팅(type casting, 형 변환)**
    - **업캐스팅(upcating)**: 특정 클래스의 객체가 상위 클래스들 중의 하나로 변형되는 것을 말함. **보장된 변환(guaranteed conversion)**이라고도 함. `as`
    - **다운캐스팅(downcasting)**: 어떤 클래스에서 다른 클래스로 만드는 변환이 일어날 때 발생함. `as!` 키워드로 수행되며, 이를 **강제 변환(forced conversion)**이라고 함.
    - 다운캐스팅을 하는 더 안전한 방법은 `as?`를 사용한 옵셔널 바인딩을 사용하는 것.
    - `is` 키워드를 사용하여 **타입 검사(type check)**를 할 수도 있음.

#### 06.01, 스위프트의 표현식 구문

가장 기본적인 스위프트 표현식: 하나의 **연산자(operator)**, 두 개의 **피연산자(operand)**, **할당자(assignment)**로 구성됨.

`var myresult = 1 + 2`

#### 06.04 복합 할당 연산자

#### 06.06 불리언 논리 연산자

- **OR(||)** 연산자는 두 개의 피연산자 중 하나가 true라고 판단되면 true를 반환하고, 두 개의 피연산자 중 어느 것도 true가 아니라면 false를 반환.
- **AND(&&)** 연산자는 두 개의 피연산자 모두 true일 때만 true를 반환함.

#### 06.07 범위 연산자

* **닫힌 범위 연산자(closed range operator)**
    `x...y`

* **반 개방 범위 연산자(half-open range operator)**
    `x..<y`

* **단 방향 범위 연산자(one-sided range operator)**
    `x...` or `...y`

#### 06.08 삼항 연산자

**삼항 연산자(ternary operator)**
    `조건문 ? 참(true)인 경우의 표현식 : 거짓(false)인 경우의 표현식`

#### 06.09 nil 병합 연산자

nil 병합 연산자(nil coalescing operator): `??`
    : 옵셔널에 nil 값이 있는 경우 디폴트 값을 사용할 수 있음.

#### 06.10 비트 연산자

**비트(bit)**
**비트 연산자(bit operator)**

NOT 비트 연산: `~`
AND 비트 연산: `&(엠퍼샌드)`
OR 비트 연산: `|`
XOR 비트 연산: 일반적으로 '배타적 논리합'이라고 부름. `^`
왼쪽 시프트 비트 연산: `<<`, 2진수의 각 비트를 지정된 횟수만큼 왼쪽으로 이동시킴. 정수의 비트를 한 자리씩 왼쪽으로 이동하면 그 정숫값은 두 배가 됨. 가장 왼쪽의 비트가 왼쪽으로 이동한 후의 결괏값이 그 값을 담는 변수의 크기를 넘으면 그 값은 무시되어 버려짐.
오른쪽 시프트 비트 연산: 2진수의 각 비트를 지정된 횟수만큼 오른쪽으로 이동시킴. 정수의 비트를 한 자리씩 오른쪽으로 이동하면 그 정숫값은 절반이 됨. `>>` 마지막 비트는 폐기됨.
    - 최상위 비트 자리에 1을 둘지, 0을 둘지는 양수 또는 음수를 가리키는 데 사용되는 **부호 비트(sign bit)**가 설정되어 있는지에 따라 결정됨.

#### 06.11 복합 비트 연산자
산술 연산자처럼 각각의 비트 연산자는 하나의 연산자를 이용하여 비트 연산을 하고 그 결과를 할당하는 연산자를 가지고 있음.
