### Chapter 07, 스위프트의 제어 흐름

어떤 프로그래밍 언어를 사용하든 애플리케이션 개발은 로직을 적용하는 작업이다.
대부분의 프로그래밍 기술은 하나 이상의 조건을 기반으로 결정해가는 코드를 작성하는 것.

**제어흐름(control flow)**
    - **반복 제어(looping control)**
    - **조건부 제어 흐름(conditional control flow)**

#### 07.01 반복 제어 흐름
for-in 반복문.

#### 07.02 스위프트 for-in 구문

```Swift
for 상수명 in 컬렉션 또는 범위 {
    // 실행될 코드
}
```

- **상수명(contant name)**: 상수로 사용되는 이름으로, 반복문이 실행되는 **컬렉션(collection)** 또는 **범위(range)**의 현재 항목(또는 값)을 담게 될 것.

##### 07.02.01 while 반복문

어떤 조건에 만족할 때까지 반복해야 하는 코드가 있는데 그 조건을 충족할 때까지 몇 번을 반복해야 하는지를 알 수 없는 경우가 있다. 이런 경우를 위해 스위프트는 while 반복문을 제공한다.

기본적으로 while 반복문은 지정된 조건에 만족할 때까지 일련의 작업을 반복함.

```swift
while 조건문 {
    // 실행될 스위프트 구문
}
```

'조건문'은 true 또는 false를 반환하는 표현식, '// 실행될 스위프트 구문'은 조건문이 true인 동안에 실행될 코드.

#### 07.03 repeat ... while 반복문

repaet ... while 반복문: while 반복문을 거꾸로 한 것. 반복문 안의 코드가 언제나 적어도 한 번은 실행되야 하는 상황을 위해 사용됨.

```swift
repeat {
    // 여기에 스위프트 구문이 온다.
} while 조건식
```

#### 07.04 반복문에서 빠져나오기

반복문에서 빠져나오기 위해서 스위프트는 현재 반복문에서 빠져나와 반복문 다음의 코드로 이동하여 실행을 계속하게 하는 break 구문을 제공한다.
