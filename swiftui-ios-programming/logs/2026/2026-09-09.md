#### 09.16 스위프트의 클로저

컴퓨터 공학 용어에서의 **클로저**는 함수나 클로저 표현식과 같은 독립적인 코드 블록과 코드 블록 주변에 있는 하나 이상의 변수가 결합된 것을 말함.

- 변수를 잡고 있다(captured), 또는 가두고 있다(closed over)

스위프트와 관련해서 **클로저**와 **클로저 표현식** 용어가 넓게 쓰이다 보니 횬용되기 시작. 중요한 점은 스위프트는 둘 다 지원한다.

(chatgpt 참고)
**클로저(closure)**는 하나의 기능/값 자체를 가리키는 넓은 개념이고,
**클로저 표현식(closure expression)**은 그 클로저를 코드로 직접 작성하는 문법입니다.

## 클로저와 클로저 표현식

| 구분 | 예시 | 의미 |
| --- | --- | --- |
| 함수 선언 | `func add(...) { ... }` | 이름이 있는 함수 정의 |
| 클로저 표현식 | `{ (a, b) in ... }` | 이름 없이 클로저를 작성하는 문법 |
| 클로저 | 함수/클로저 표현식 등을 포함하는 더 넓은 개념 | 실행 가능한 기능을 하나의 값처럼 다루는 것 |
| 클로저 타입 | `(Int, Int) -> Int` | 입력과 출력의 형태 |

특히 책을 읽을 때는 **"클로저"와 "클로저 표현식"을 완전히 별개의 것으로 생각하면 오히려 헷갈릴 수 있다.**

다음처럼 생각하면 된다.

```text
클로저
 ├─ 전역 함수
 ├─ 중첩 함수
 └─ 클로저 표현식으로 만든 익명 클로저
```

* 클로저 표현식에서 Swift가 반환 타입을 추론할 수 있다.

### Chapter 10 스위프트의 객체지향 프로그래밍 기초

#### 10.01 객체란 무엇인가?
객체(또는 클래스 인스턴스)는 소프트웨어 애플리케이션을 구축하는 블록으로 쉽게 사용하고 재사용할 수 있는 독립적인 기능 모듈.

작업을 수행하기 위한 객체나 인스턴스에서 접근되고 호출되는 속성(프로퍼티 property)과 함수(메서드 method)로 객체가 구성됨. 객체를 구성하는 데이터 변수와 함수를 포괄적으로 **클래스 멤버(class member)**라고 함.

#### 10.02 클래스란 무엇인가?
클래스는 객체가 생성될 때의 모습을 정의함. 예를 들어, 메서드들이 하게 될 일이 무엇이며 어떤 프로퍼티들이 존재할지 등을 정의.

#### 10.03 스위프트 클래스 선언

새로운 클래스에 대한 기본 구문
```swift
class 새로운 클래스 이름: 부모 클래스 {
    // 프로퍼티
    // 인스턴스 메서드
    // 타입 메서드
}
```

- 선언부의 **프로퍼티** 부분은 이 클래스 내에 포함될 변수와 상수를 정의. 스위프트에서 변수나 상수를 선얼할 때와 동일한 방법으로 선언.

- **인스턴스 메서드(instance method)**와 **타입 메서드(type method)** 부분은 이 클래스에서 호출되는 메서드들과 클래스의 인스턴스들을 정의. 본질적으로 이것들은 특정 작업을 수행하는 클래스 고유의 함수.

- 클래스 이름을 지을 때 규칙은 각 단어의 첫 번째 문자를 대문자로 선언. UpeerCamelCase.
- 이와 대조적으로 프로퍼티 이름과 함수의 이름은 lowerCamelCase처럼 첫 번째 문자를 소문자로 함.

#### 10.04 클래스에 인스턴스 프로퍼티 추가

객체 지향 프로그래밍의 핵심 목적은 **데이터 캡슐화(data encapsulation)**라는 개념.

* 데이터 캡슐화: 클래스에 저장되고 접근될 수 있는 데이터는 오직 해당 클래스 내에 정의된 메서드만을 통해서 된다는 것.

- 클래스 내의 캡슐화된 데이트를 **프로퍼티** 또는 **인스턴스 변수(instance variable)**라고 함.

#### 10.05 메서드 정의하기
본질적으로 클래스의 메서드는 클래스의 성격에 맞는 특정 작업을 수행하기 위해 호출되는 코드 루틴.

- 메서드는 **타입 메서드**와 **인스턴스 메서드**의 서로 다른 두 가지 형태로 나뉨.
    - 타입 메서드: 클래스 레벨에서 동작(예를 들어, 클래스의 새로운 인스턴스 생성하기)
    - 인스턴스 메서드: 클래스의 인스턴스에 대한 작업(예를 들어, 두 개의 프로퍼티 변수에 대한 산술 연산을 하고 결과를 반환하는 것)

    - 인스턴스 메서드는 자신이 속하게 될 클래스의 여는 괄호와 닫는 괄호 안에 선언되며, 표준 스위프트 함수 선언 구문을 사용하여 선언.
    - 타입 메서드는 인스턴스 메서드와 동일한 방법으로 선언되지만, 선언부 앞에 class 키워드가 붙는다는 점이 다름.

#### 10.06 클래스 인스턴스 선언하기와 초기화하기

#### 10.07 클래스 인스턴스 초기화하기와 소멸하기

클래스는 인스턴스를 생성하는 시점에 해야 할 초기화 작업이 있을 수 있음. 이 작업은 클래스의 init 메서드 안에 구현됨.

반대로, 스위프트 런타임 시스템에 의해 클래스 인스턴스가 없어지기 전에 해야 할 정리 작업은 클래스 안에 **소멸자(deinitializer)**를 구현하면 할 수 있음.

#### 10.08 메서드 호출하기와 프로퍼티 접근하기

* **점 표기법(dot notation)**
    - 점 표기법을 사용하면 클래스 인스턴스 다음에 점을 찍고 그 뒤에 프로퍼티나 메서드 이름을 써서 인스턴스 변수에 접근하거나 인스턴스 메서드를 호출하게 됨.

    ```swift
    클래스인스턴스.프로퍼티명
    클래스인스턴스.인스턴스메서드()
    ```

    - 점 표기법을 사용하면 인스턴스 프로퍼티에 값을 설정할 수도 있음.
    - 클래스 인스턴스의 메서드를 호출할 때도 같은 방법을 사용함.

    - 타입 메서드 역시 점 표기법을 이용하여 호출됨. 다만, 주의할 점은 클래스 인스턴스가 아니라 클래스에서 호출되어야 함.
    ```swift
    클래스이름.타입메서드()
    ```

#### 10.09 저장 프로퍼티와 연산 프로퍼티

스위프트의 클래스 프로퍼티는 **저장 프로퍼티(stored property)**와 **연산 프로퍼티(computed property)**로 나뉨.

* 저장 프로퍼티: 상수나 변수에 담기는 값.
* 연산 프로퍼티: 프로퍼티에 값을 성정하거나 가져오는 시점에서 어떤 계산이나 로직에 따라 처리된 값.

- 연산 프로퍼티는 **게터(getter)**를 생성하고 선택적으로 **세터(setter)** 메서드를 생성하며, 연산을 수행할 코드가 포함됨.
