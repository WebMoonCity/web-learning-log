### Chapter 08, 스위프트의 switch 구문

if...else 구문은 제한된 개수의 조건을 검사할 때는 적절. 많은 수의 조건을 처리할 때는 부적절.
이런 상황을 해결하기 위하여 스위프트는 C 언어의 switch 구문을 가져옴.
다른 언어의 switch 구문과 스위프트의 switch 구문에는 몇 가지 중요한 차이점이 있음.

#### 08.01. 왜 switch 구문을 사용하나?

두세 개 이상의 조건을 만들 때, switch 구문은 최고의 대안이 될 것.

#### 08.02, switch 구문 사용하기.

```Swift
switch 표현식 {
    case 일치하는 값1:
        코드 구문

    case 일치하는 값2:
        코드 구문

    case 일치하는 값3, 일치하는 값4:
        코드 구문

    default:
        코드 구문
}
```

- **표현식(expression)**:
    값을 나타내거나 값을 반환하는 표현식. 이 값은 switch 구문이 동작하게 하는 값.
    이 값과 일치할 수 있는 값을 case 구문으로 제공. 앞으 구문에서 '일치하는 값'에 해당.
- 각각의 일치하는 값은 '표현식'의 값과 동일한 타입이어야 함.
- case 조건과 일치하는 값일 경우에 수행될 '코드 구문'이 case 줄 아래에 작성됨.
- 마지막으로, default 절은 표현식과 일치하는 case 구문이 없을 경우에 어떻게 해야 하는지를 정의하는 부분.

# Swift Learning Log — Optional, Unwrapping, Argument Label, guard

## 핵심 정리

1. **`Int?`는 Optional Int다.**
   - `Int` 값이 있을 수도 있고 `nil`일 수도 있는 타입이다.
   - `Int?`는 `Optional<Int>`의 축약형이다.

2. **`Optional(10)`은 Optional 안에 `10`이 들어 있는 상태를 뜻한다.**
   - 값이 있는 상태: `.some(10)`
   - 값이 없는 상태: `.none` 또는 `nil`

3. **언래핑(Unwrapping)은 Optional 안에 실제 값이 있는지 확인하고, 있다면 그 값을 꺼내 사용하는 것이다.**
   - 예: `Int? → Int`

4. **`guard let`은 일반 대입이 아니라 Optional Binding이다.**
   - 값이 있으면 언래핑하여 새 상수나 변수에 넣는다.
   - 값이 `nil`이면 바인딩에 실패하고 `else`로 간다.

```swift
guard let number = value else {
    return
}
```

5. **Swift의 `:`는 항상 타입을 뜻하지 않는다. 문맥을 확인해야 한다.**

선언에서는:

```swift
let age: Int
```

- `이름: 타입`

함수 호출에서는:

```swift
multiplyByTen(value: 10)
```

- `인자 레이블: 전달할 값`

6. **인자 레이블(Argument Label)은 전달하는 값에 붙이는 이름표다.**

```swift
multiplyByTen(value: 10)
```

- `value` → 인자 레이블
- `10` → 인자

7. **인자 레이블과 함수 내부의 매개변수 이름을 다르게 만들 수도 있다.**

```swift
func greet(to person: String) {
    print(person)
}
```

- `to` → 인자 레이블
- `person` → 함수 내부에서 사용하는 매개변수 이름
- `String` → 타입

호출:

```swift
greet(to: "철수")
```

8. **`guard`의 쉼표는 나열된 조건이나 바인딩이 모두 성공해야 한다는 뜻으로 볼 수 있다.**

```swift
guard let number = value, number < 10 else {
    return
}
```

의미:

- `value` 언래핑 성공
- AND
- `number < 10`

하나라도 실패하면 `else`가 실행된다.

# 주요 용어 정리

## Optional

값이 있을 수도 있고 없을 수도 있는 타입.

```swift
let number: Int?
```

`number`에는 정수가 들어갈 수도 있고 `nil`이 들어갈 수도 있다.

---

## `nil`

Optional에 값이 없는 상태.

```swift
let number: Int? = nil
```

---

## `.some`

Optional에 실제 값이 있는 상태.

```swift
.some(10)
```

의미:

> Optional 안에 `10`이 들어 있다.

---

## `.none`

Optional에 값이 없는 상태.

```swift
.none
```

`nil`과 대응되는 개념이다.

---

## Unwrapping

Optional 안에 실제 값이 있는지 확인하고, 있다면 그 값을 꺼내 사용하는 것.

```text
Int? → Int
```

예:

```swift
let value: Int? = 10

guard let number = value else {
    return
}
```

결과적으로:

```text
value  : Int?
number : Int
```

---

## Optional Binding

Optional에 값이 있을 때만 그 값을 꺼내 새 변수나 상수에 연결하는 문법.

대표적인 형태:

```swift
if let
guard let
```

예:

```swift
guard let number = value else {
    return
}
```

---

## Parameter — 매개변수

함수를 **정의할 때 값을 받을 자리**.

```swift
func multiply(value: Int) {
    print(value * 10)
}
```

여기서 `value`가 매개변수이다.

---

## Argument — 인자

함수를 **호출할 때 실제로 전달하는 값**.

```swift
multiply(value: 10)
```

여기서 `10`이 인자이다.

### 매개변수와 인자의 차이

```swift
func multiply(value: Int) {
              ↑
            매개변수
}

multiply(value: 10)
                ↑
               인자
```

간단히 기억:

```text
매개변수(Parameter)
= 함수를 만들 때 값을 받을 자리

인자(Argument)
= 함수를 호출할 때 실제로 넣는 값
```

---

## Label — 레이블

이름표 또는 표지라는 뜻.

값의 역할을 알아보기 쉽게 표시하는 이름이다.

---

## Argument Label — 인자 레이블

함수를 호출할 때 **전달하는 인자가 어떤 역할을 하는 값인지 나타내는 이름표**.

```swift
move(from: "서울", to: "부산")
```

- `from` → 인자 레이블
- `"서울"` → 인자
- `to` → 인자 레이블
- `"부산"` → 인자

---

# `to person` 이해하기

```swift
func greet(to person: String) {
    print(person)
}
```

구조:

```text
to      person   String
↑       ↑        ↑
인자     매개변수   타입
레이블   이름
```

함수 호출:

```swift
greet(to: "철수")
```

함수 밖에서는:

```text
to
```

를 사용한다.

함수 안에서는:

```text
person
```

을 사용한다.

즉:

```swift
func greet(to person: String)
```

에서

- `to` = 외부에서 사용하는 인자 레이블
- `person` = 함수 내부에서 사용하는 매개변수 이름

문법적으로는 다음처럼 이름을 지을 수도 있다.

```swift
func greet(a b: String) {
    print(b)
}
```

호출:

```swift
greet(a: "철수")
```

하지만 의미를 알기 어렵기 때문에 보통 `to person`처럼 읽기 좋은 이름을 사용한다.

# `:` 정리

Swift에서 `:`는 문맥에 따라 의미가 달라진다.

## 선언

```swift
let age: Int
```

```text
이름: 타입
```

## 함수 매개변수 선언

```swift
func foo(value: Int)
```

```text
매개변수 이름: 타입
```

## 함수 호출

```swift
foo(value: 10)
```

```text
인자 레이블: 전달할 값
```

따라서 Swift의 `:`를 무조건 "타입 선언 기호"라고 외우지 말고 문맥을 확인한다.

# 한 코드로 전체 복습

```swift
func multiplyByTen(value: Int?) {
    guard let number = value, number < 10 else {
        return
    }

    let result = number * 10
    print(result)
}

multiplyByTen(value: 5)
```

해석:

```text
value: Int?
→ value는 Optional Int 매개변수

multiplyByTen(value: 5)
→ value는 인자 레이블
→ 5는 실제 인자

guard let number = value
→ value에 실제 값이 있는지 확인
→ 값이 있으면 언래핑
→ number는 Int가 됨

number < 10
→ 추가 조건 검사

두 조건을 모두 만족
→ guard 통과

number * 10
→ number는 이미 Int이므로 안전하게 계산 가능
```

## 한 줄 핵심

```text
Int? = 값이 없을 수도 있는 Int

Unwrapping = Optional 안의 실제 값을 확인하고 꺼내는 것

guard let = Optional Binding

Parameter = 함수 정의에서 값을 받을 자리

Argument = 함수 호출에서 실제로 전달하는 값

Argument Label = 전달하는 인자의 역할을 나타내는 이름표
```
