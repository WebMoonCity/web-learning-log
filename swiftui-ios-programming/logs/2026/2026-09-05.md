#### 09.14 클로저 표현식

* **클로저(closure)**, **클로저 표현식(closure expression)**
    클로저 표현식: 독립적인 코드 블록
    
    ```swift
    {(<매개변수 이름>: <매개변수 타입>, <매개변수 이름>: <매개변수 타입>, ... ) -> <반환 타입> in
        // 클로저 표현식 코드가 온다.
    }
    ```

    이 구문은 함수를 선얼할 때 사용하는 것과 비슷하지만, 클로저 표현식은 이름을 갖지 않으며, 매개변수와 반환 타입은 괄호 안에 포함되고, 클로저 표현식 코드의 시작을 카리키기 위햐여 in 키워드를 사용함. 사실, ***함수는 이름이 있는 클로저 표현식일 뿐.***\

    "사실, 스위프트 컴파일러는 이 메서드 호출에 대한 완료 핸들러의 매개변수와 반환값에 대해 이미 알고 있기 때문에 클로저 표현식 내에서 선언되지 않은 정보를 유추할 수 있다. 따라서 클로저 표현식의 선언부를 다음과 같이 간략하게 할 수 있다."
