### Chapter 05, 스위프트 데이터 타입, 상수, 그리고 변수

Swift는 더 쉽고 빠르게 프로그래밍할 수 있으며, 프로그래머의 오류를 줄여주기 위해 설계된 비교적 새로운 프로그래밍 언어다.

#### Chapter 05.01, 스위프트 플레이그라운드 사용하기

스위프트를 배우기 위한 가장 좋은 방법: 스위프트 플레이그라운드 환경에서 이것저것 해보는 것

#### Chapter 05.02, 스위프트 데이터 타입

- **비트(bit)**: 각각의 1 또는 0
- **바이트(byte)**: 8개의 비트가 모임

프로그래밍 언어들은 우리가 이해하는 구조와 명령을 컴퓨터에게 전달, CPU에 의해 실행될 수 있는 형태로 컴파일해줌.

- 모든 프로그램의 기본 중의 하나가 데이터.
- 스위프트와 같은 프로그래밍 언어는 **데이터 타입(data type)**을 정의함.

##### Chapter 05.02.01, 정수형 데이터 타입

##### Chapter 05.02.02, 부동소수점 데이터 타입

스위프트의 부동소수점 데이터 타입은 소수점이 있는 값을 저장할 수 있는 데이터 타입.

- **Float** or **Double**
- Double 데이터 타입: 최대 64비트의 부동소수점 수를 저장하기 위해 사용. 코드가 실행되는 플랫폼에 따라 적어도 15자리까지 표현할 수 있음.
- Float 데이터 타입: 최대 32비트의 부동소수점 수를 저장하기 위해 사용함. 적어도 6자리까지 표현. 또는 Float16 유형을 사용하여 16비트의 부동 소수점 값을 저장할 수 있음. Float16은 낮은 정밀도를 대가로 더 나은 성능을 제공.

##### Chapter 05.02.03, 불리언 데이터 타입

- **불리언(Boolean)** 데이터 타입: 참/거짓(또는 1과 0)을 처리하는 목적의 데이터 타입. 두 개의 불리언 상숫값인 true와 false를 제공.

##### Chapter 05.02.04, 문자 데이터 타입

스위프트의 문자 데이터 타입은 문자, 숫자, 문장 부호, 기호와 같은 하나의 문자를 저장하는 데 사용됨.
스위프트에서 문자는 내부적으로 **그래핌 클러스터(grapheme cluster)**의 형태로 저장됨.

- 그래핌 클러스터: 눈에 보이는 하나의 문자를 표현하기 위해 결합된 둘 이상의 유니코드 스칼라로 구성.

##### 05.02.06 문자열 데이터 타입

- 문자열은 내부적으로 문자들의 집합으로 표시
- **문자열 보간(string interpolation)**
- 여러줄의 문자열은 삼중 따옴표 안에 넣어서 선언 가능.

##### 05.02.06, 특수 문자/이스케이프 시퀀스

- **이스케이프 시퀀스(escape sequence)**: 개행, 탭 또는 문자열 내에 특정 유니코드 값을 지정.
- **이스케이핑(escaping)**: 특수 문자들은 역슬래시 문자를 앞에 써서 구별하게 됨.

#### 05.03 스위프트 변수

본질적으로 **변수(variable)**는 애플리케이션이 사용하는 데이터를 저장하기 위해 예약된 컴퓨터 메미로 내의 위치.
각각의 변수는 프로그래머에 의해 이름이 주어지고 값이 할당됨.
변수에 할당된 이름은 변수에 할당된 값을 스위프트 코드 내에서 접근하기 위해 사용됨.
물론, 변수에 할당된 값을 변경할 수도 있음.

#### 05.04 스위프트 상수

**상수(constant)**도 변수처럼 데이터 값을 저장하기 위해 매모리 내의 위치에 이름을 명명함.
한 가지 큰 차이점은 값이 한번 할당되면 나중에 그 값을 바꾸지 못한다는 점.

- 상수는 애플리케이션 코드 내에서 반복적으로 사용되는 값이 있을 때 특히 유용함.
- 상수의 장점
    1. 코드의 가독성
    2. 애플리케이션 코드 내의 여러 곳에서 어떤 상수를 사용하고 있고 그 값을 전체적으로 변경해야 할 경우에, 상수 선언부에서 한 번만 수정하면 모두 적용된다는 점.
- 변수와 마찬가지로 상수 역시 데이터 타입과 이름, 그리고 값을 갖지만, 상수에 한번 할당된 값은 프로그램 실행 중에 바꿀 수 없다는 점이 다름.

#### 05.05 상수와 변수 선언하기

변수는 var 키워드를 사용하여 선언. 변수를 생성할 때 값으로 초기화할 수 있음.
변수가 초깃값 없이 선언되었다면, 이번 장 후반부에서 설명할 **옵셔널(optional)**로 선언된 것으로 간주함.

```swift
var backslash = "\\" // 변수
let maxUserCount = 20 // 상수는 let 키워드를 사용하여 선언.
```

* 애플은 코드의 효율성과 실행 성능의 향상을 위해서 가능하면 변수보다 상수를 사용하라고 권장하고 있음.
