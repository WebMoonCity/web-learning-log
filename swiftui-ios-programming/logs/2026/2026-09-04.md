### Chapter 09 스위프트의 함수, 메서드, 클로저

스위프트의 함수, 메드, 클로저는 체계적인 구조와 효율적인 코드를 작성하는 핵심 부분.
코드의 반복을 피하면서 프로그램을 구조화하는 방법을 제공함.

이번 장에서 함수, 메서드, 클로저를 어떻게 선언하며 사용하는지를 살펴볼 것.

#### Chapter 09.01 함수란 무엇인가?

* 함수: 특정 작업을 수행하기 위해 호출할 수 있게 이름 붙여진 코드 블록. 작업을 수행하기 위한 데이터가 제공될 수 있고 작업의 결과를 호출한 코드로 반환할 수도 있음.
    - **매개변수(parameter)**
    - **인자(argument)**
    - **매개변수**와 **인자**: 함수가 호출될 때 받게 되는 값을 매개변수라고 함. 실제로 함수가 호출되고 값이 전달된 시점에서는 인자라고 부름.

#### 09.02 메서드
본질적으로 메서드는 특정 클래스나 구조체 또는 열거형과 연관된 함수.
스위프트 클래스 내에서 함수를 선언했다면 이것은 메서드로 간주됨.
특별한 언급이 없다면 함수에 대해 설명하는 규칙과 동작 모두가 메서드에도 동일하게 적용.

#### 09.03 스위프트 함수 선언

```swift
func <함수명> (<매개변수 이름>: <매개변수 타입>,
            <매개변수 이름>: <매개변수 타입>, ... ) -> <반환 결과 타입> {
                // 함수 코드
}
```

* 함수명, 매개변수, 그리고 반환 결과 타입의 조합을 **함수 시그니처(funciton signature)**라고 부름.

#### 09.04 단일 표현식에서의 암묵적 변환
만약 함수가 단일 표현식을 가지고 있다면 return 구문을 생략할 수 있다.
return 구문은 함수가 단일 표현식을 가지고 있을 때만 생략 가능. 두 개의 표현식을 가지고 있을 때는 안됨.

#### 09.05 스위프트 함수 호출

`<함수명> (<인자1>, <인자2>, ... )`

- 함수를 통해 전달되는 각각의 인자는 함수가 받도록 구성된 매개변수와 일치해야 함.

#### 09.07 지역 매개변수명, 외부 매개변수명

* **지역 매개변수명(local parameter name)**: 함수들을 **선언**할 때 함수 코드 내에서 참조할 수 있는 이름을 할당한 매개변수로 구성. 이렇게 선언된 매개변수.
* **외부 매개변수명(external parameter name)**: 이들 이름은 함수가 **호출**될 때 참조되는 매개변수의 이름.
- 기본적으로, 함수 매개변수에는 동일한 지역 매개변수명과 외부 매개변수명이 할당됨.

* 매개변수에 할당된 디폴트 외부 매개변수명은 다음과 같이 지역 매개변수명 앞에 밑줄 문자(underscore)를 써서 없앨 수 있다.
- 함수 선운부에서 지역 매개변수명 앞에 외부 매개변수명을 선언하면 간단하게 외부 매개변수명이 추가됨.

* 함수를 호출할 때 인자를 전달하기 위하여 외부 매개변수명이 사용됨에도 함수 내에서 매개변수를 참조할 때는 여전히 지역 매개변수명이 사용됨.
* 또한, 기억해야 할 점은 인자에 대한 외부 매개변수명을 사용하여 함수를 호출할 때는 함수를 선언했을 때와 동일한 순서로 인자를 넣어야 한다는 것.


#### 핵심 용어 대응[추가 chatgpt 정리]

```text
외부 매개변수명(external parameter name)
= 인자 레이블(argument label)

지역/내부 매개변수명(local parameter name)
= 매개변수 이름(parameter name)

인자(argument)
= 함수를 호출할 때 실제로 전달하는 값
```

#### 09.08 함수에 디폴트 매개변수 선언하기
* 스위프트는 함수가 호출될 때 인자로 쓸 값이 들어오지 않은 경우에 사용할 디폴트 매개변수 값을 지정할 수 있음.
* 함수를 선언할 때 매개변수에 디폴트 값을 할당하면 됨.
* 또한, 스위프트는 함수를 호출할 때 반드시 사용되는 디폴트 값을 설정한 매개변수에 대해 지역 매개변수명을 기반으로 한 디폴트 외부 매개변수명을 제공함. ->(chatgpt 정리) 디폴트 값이 설정된 매개변수는 기본적으로 내부 매개변수명을 바탕으로 같은 이름의 외부 매개변수명(인자 레이블)을 제공한다.

```swift
func buildMessageFor(_ name: String = "Customer", count: Int ) -> String
{
    return ("\(name), you are customer number \(count)")
}

let message = buildMessageFor(count: 100)
print(message) // Customer, you are customer number 100
```

#### 09.10 함수 매개변수의 변수 개수

* **가변 매개변수(variadic parameter)**
* 함수가 지정된 데이터 타입의 매개변수 0개 또는 그 이상을 받는다는 것을 의미하는 점 세 개 `...`를 이용하여 가변 매개변수를 선언함.

#### 09.11 변수인 매개변수
* 함수가 받는 모든 매개변수는 기본적으로 상수로 취급. 함수의 코드 내에서 매개변수의 값이 변경 되는 것을 막음.
* 만약 함수 내에서 매개변수의 값을 변경하고 싶다면, 매개변수의 **섀도 복사본(shadow copy)**을 반드시 생성해야 함.

#### 09.12 입출력 매개변수로 작업하기

함수가 값을 반한한 뒤에도 매개변수에 대한 변경을 유지하려면, 함수 선언부 내에서 매개변수를 **입출력 매개변수(in-out parameter)**로 선언해야 함. 마지막으로, 함수를 호출할 때 입출력 매개변수 앞에 &을 붙여야 함.

```swift
func doubleValue (_ value: inout Int) -> Int {
    value += value
    return(value)
}

print("Befoure function call myValue = \(myValue)")

print("doubleValue call returned \(doubleValue(&myValue))") //: 매개 변수 앞에 &을 붙여야 함.

print("After function call myValue = \(myValue)")
```
