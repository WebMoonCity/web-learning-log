## 핵심 구조

템플릿 v02는 하루 전체를 한꺼번에 기록하지 않고, 실제로 공부한 시간 단위인 **세션**별로 내용을 기록한다.

1. `기본 정보`에는 하루 전체의 목표와 합계를 적는다.
2. `세션 1`, `세션 2`에는 각 학습 시간과 내용을 독립적으로 적는다.
3. `하루 마무리`에는 여러 세션에서 배운 내용을 하나로 정리한다.

세션 수는 고정되어 있지 않다. 하루에 한 번 공부했다면 `세션 2`를 삭제하고, 세 번 이상 공부했다면 세션 블록을 복사하여 번호를 늘린다.

- `막힘`: 해결되지 않은 구체적인 문제 때문에 다음 단계로 진행할 수 없다.

## 세션 1

- 시작 시간: `09:00`
- 종료 시간: `09:25`
- 공부 시간: 25분
- 장/절: SwiftUI 상태 관리 / `@State`
- 페이지: 120-123쪽
- 세션 목표: `@State`를 사용한 카운터를 실행한다.
- 학습한 내용:
  - `@State`는 뷰가 소유하는 변경 가능한 상태를 저장한다.
  - 상태가 바뀌면 SwiftUI가 해당 상태에 의존하는 화면을 다시 계산한다.
- 핵심 한 줄: 화면을 직접 고치는 대신 상태를 바꾸면 SwiftUI가 화면을 갱신한다.
- 직접 구현한 것: 증가·감소 버튼과 현재 숫자를 표시하는 `CounterView`
- 책을 덮고 다시 만든 것: `@State private var count = 0`과 증가 버튼
- 바꿔 본 것: 초기화 버튼을 추가하고 초기값을 5로 변경했다.
- 예상 결과: 초기화 버튼을 누르면 숫자가 0으로 바뀐다.
- 실제 결과: 예상대로 0으로 바뀌고 화면도 즉시 갱신됐다.
- 막힌 점: 일반 프로퍼티인 `count`를 버튼에서 변경하자 컴파일 오류가 발생했다.
- 시도한 것: 오류 메시지를 읽고 일반 프로퍼티와 `@State` 프로퍼티를 비교했다.
- 원인: `View`의 일반 저장 프로퍼티를 직접 변경하려 했기 때문이다.
- 해결 방법: `count`를 `@State private var`로 선언했다.
- 확인한 근거: 빌드가 성공했고 버튼을 누를 때 `Text`의 숫자가 바뀌었다.
- 책과 현재 환경의 버전 차이: 책의 `PreviewProvider` 대신 현재 Xcode에서는 `#Preview`를 사용할 수 있다.
